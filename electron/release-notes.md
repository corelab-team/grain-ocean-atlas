Автономное Windows-приложение «Путь зерна» (x64).

- `GrainOceanAtlas-1.0.9-win-x64-Setup.exe` — установщик с русским интерфейсом, выбором папки, ярлыками на рабочем столе и в меню «Пуск». Удаление через настройки Windows.
- `GrainOceanAtlas-1.0.9-win-x64.zip` — переносимая сборка: распаковать целиком и запустить `GrainOceanAtlas.exe`.
- На карте экспорта добавлена кнопка «Сброс» по Фигме: возвращает исходный ракурс и масштаб глобуса с Россией по центру.
- Обновлены своды мягкой и твёрдой пшеницы на 28.09.2026 и список 47 регионов с сильной пшеницей.
- Исправлены размеры изображения масла по Фигме, нижние отступы карточек продуктов и постоянный цвет заголовка экспорта.
- При самостоятельном поиске сорняков скрываются перекрывающие поле плашки; кнопка запуска БПЛА остаётся доступна.
- Заставка использует присланное видео grain-loop-v5-slow.mp4: автозапуск, повтор без звука, локальное воспроизведение без интернета.
- Оформление обновлено по макетам Фигмы от 02.10 и комментариям дизайнера. Сохранены согласованные решения из PDF: без ключевых показателей в центре, с работающим техническим маршрутом.
- Все видео, изображения, шрифты и данные включены. Установка и работа приложения не требуют интернета.
- По умолчанию открывается полноэкранный режим стенда. Выход — Ctrl+Shift+Q или Alt+F4.
- `SHA256SUMS.txt` содержит контрольные суммы файлов.

Установщик пока без цифровой подписи издателя; Windows может показать предупреждение SmartScreen.
