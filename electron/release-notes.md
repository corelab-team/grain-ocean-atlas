Автономные «Маршруты экспорта» для Windows x64.

- Глобус уменьшен и расположен по кадру Фигмы 754:2128 для видеостены. «Сброс» возвращает этот новый размер и положение.
- Название выбранной страны окрашено по Фигме; «Сброс» перенесён в правый верхний угол на место главного меню.
- Приложение сразу открывается на весь экран с экспортным глобусом.
- В сборке только страница «Маршруты экспорта», без кнопки «Главное меню».
- Сохранены поиск стран, выбор года, карточки стран и кнопка «Сброс».
- Все данные, изображения, шрифты и видео локальные. Интернет для работы не нужен.
- Выход — Ctrl+Shift+Q или Alt+F4. Для оконного режима — аргумент --windowed.
- Устанавливается отдельно от полной версии, ярлык «Маршруты экспорта».

Установщик пока без цифровой подписи издателя.
