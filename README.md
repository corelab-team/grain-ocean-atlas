# Маршруты экспорта — отдельная Windows-сборка

Ветка `codex/export-only` содержит автономное приложение только с экспортным глобусом. При запуске сразу открывается полноэкранная карта, кнопки «Главное меню» нет. Поиск, годы, карточки стран и «Сброс» сохранены. Интернет не требуется.

Сборка ресурсов: `python3 3d-dark/tools/build_export_only.py`. Затем на Windows: `pnpm install --frozen-lockfile`, `pnpm test`, `pnpm pack:win`, `pnpm test:electron`, `pnpm dist:win`.

Результат — `release/GrainExportAtlas-1.0.2-win-x64-Setup.exe`. Устанавливается рядом с полной версией, ярлык «Маршруты экспорта». Выход — Ctrl+Shift+Q или Alt+F4. Установщик без цифровой подписи.

Ниже сохранено описание исходного проекта.

# Путь зерна — морские маршруты

Интерактивная демонстрация для сенсорной панели 1920×1080. Статическое приложение с Three.js r170 и WebGL 2, без сборки и внешних запросов во время работы.

## Windows-приложение на Electron

В ветке `electron` стенд упакован в автономное приложение Windows x64. В оболочке открывается актуальное единое приложение `dist/app/index.html`: презентация, глобус и госмониторинг. Видео, шрифты, изображения, библиотеки и данные входят в поставку; установленный Node.js, Python и подключение к интернету для запуска не нужны.

Для обычной установки используйте `release/GrainOceanAtlas-1.0.23-win-x64-Setup.exe`: русский интерфейс, выбор папки, ярлыки на рабочем столе и в меню «Пуск», удаление через настройки Windows. Все файлы встроены в установщик; сеть не требуется. Приложение не запускается автоматически после установки. Установщик пока без цифровой подписи издателя.

Переносимая сборка — `release/GrainOceanAtlas-1.0.23-win-x64.zip`. Распакуйте архив целиком и запустите `GrainOceanAtlas.exe`. Папка `resources` должна оставаться рядом с EXE. По умолчанию приложение открывается в полноэкранном режиме стенда и не даёт экрану уснуть. Выход — **Ctrl+Shift+Q** или **Alt+F4**. Для оконного режима запустите EXE с аргументом `--windowed`.

Для разработки и сборки на Windows нужны Node.js 24 и pnpm 11.25.0. Используйте локальную папку Windows (например, `C:\Work\grain-ocean-atlas`), поскольку команды сборки не поддерживают сетевой UNC-путь к WSL:

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm start:windowed
pnpm dist:win
```

`pnpm start` включает полноэкранный режим; `pnpm pack:win` создаёт распакованную сборку в `release/win-unpacked`. Проверка реального Electron: `pnpm test:electron` для исходников или `node electron/smoke.cjs release/win-unpacked/GrainOceanAtlas.exe` для готовой сборки. Проверка запускается со скрытым окном, отключает сеть Chromium и проверяет стартовый коллаж, видео, перемотку, поиск, карточки сорняков и глобус.

Перед упаковкой после правок сайта обновите `dist/app` через `python3 3d-dark/tools/publish_pages.py`. При обычной упаковке используются уже сохранённые в Git страницы и ресурсы, Python не нужен. Интернет требуется только разработчику при установке зависимостей и первом скачивании Electron для сборки.

Локальные ресурсы обслуживаются через `atlas://app`, без HTTP-сервера и сетевых портов. Оболочка блокирует интернет-запросы, внешние переходы, новые окна и скачивания. Renderer работает в sandbox с изоляцией контекста, без доступа к Node.js. Обновления приложения выполняются заменой всей распакованной сборки.

Windows-сборка также запускается через Actions → **Build offline Windows application**. EXE, ZIP и `SHA256SUMS.txt` появляются в артефакте `grain-ocean-atlas-windows-x64`; готовые EXE и ZIP не сохраняются в Git. После успешной проверки установщика теги `electron-v*` автоматически публикуют эти файлы в GitHub Releases. Для проверки установки и удаления используйте `./electron/test-installer.ps1` из PowerShell в отдельной учётной записи без ранее установленного приложения.

## Запуск исходной морской демоверсии

Следующие разделы описывают отдельную раннюю демоверсию из `dist/`. Актуальное приложение стенда и Windows-сборка описаны выше.

Сервируйте папку `dist` любым локальным HTTP-сервером. Например, при установленном Python: `python -m http.server 8080 --directory dist`, затем откройте `http://localhost:8080`. Открытие через `file://` не поддерживается из-за ES modules и загрузки GeoJSON. Все необходимые ресурсы включены в папку. Для поставки по ТЗ потребуется отдельная Windows-оболочка с запуском локального сервера и полноэкранного окна; EXE в эту демонстрацию не входит.

## Содержание

- Объёмная геометрия стран по Natural Earth 1:50m.
- Вода из официального примера Three.js Ocean: модуль Water с плоскими отражениями сцены и готовыми нормалями, модуль Sky. Небольшая геометрическая зыбь добавлена адаптером.
- Модель сухогруза, портовые маркеры, демонстрационные маршруты в Египет, Турцию, Алжир, Саудовскую Аравию и Италию.
- Выбор страны в списке и на карте, поиск, масштабирование, переключение «Море / Карта», управление поездкой и анимацией.
- Возврат в исходное состояние через 120 секунд бездействия, пауза при скрытии вкладки.
- Адаптация к узким экранам и режим сниженного разрешения рендера.

`dist/routes.js` содержит направления, условные объёмы и координаты маршрутов. Для обновления пересборка не нужна. `dist/ocean.js` — адаптер готовой воды, `dist/shaders.js` — материал суши. `dist/app.js` — сцена и взаимодействия. `dist/style.css` — интерфейс.

## Границы демоверсии

Поставки являются демонстрационными. Маршруты схематичны и не предназначены для морской навигации. Это прототип экспортного блока, не полное приложение по ТЗ. Карта мониторинга регионов РФ, девять этапов «Пути зерна», импорт Excel и Windows EXE пока не реализованы.

Проверены синтаксис JavaScript, геометрия всех отображаемых полигонов, соответствие идентификаторов стран и наличие ресурсов/элементов интерфейса. Исправлен запуск океана при системной настройке reduced motion: анимация воды запускается как основное содержание экспозиции, а явная кнопка паузы останавливает её. Проверка фактического GLSL через программное выполнение подтвердила изменение изображения между двумя моментами времени; это не заменяет проверку GPU в браузере. На целевом компьютере необходимо проверить WebGL, производительность 1920×1080, сенсор и длительную автономную работу. Браузерная визуальная проверка в этой сессии не проводилась.

## Проверка шейдеров

`node scripts/validate-shaders.mjs /path/to/glslangValidator` компилирует и связывает реальные шейдеры воды и суши как GLSL ES 3.00, с фрагментами Three.js для цветового пространства и tone mapping. Нужен официальный `glslangValidator` из KhronosGroup/glslang.

Проверка ловит ошибку, при которой имя переменной `patch` (зарезервированное слово GLSL) не позволяло скомпилировать воду, оставляя видимым только фон. После переименования в `waterTint` обе пары шейдеров проходят проверку. Проверка JavaScript и программное вычисление GLSL такую несовместимость языка не выявляли. При ошибке компиляции на устройстве приложение теперь показывает сообщение о невозможности запуска графики вместо молчаливого пустого моря.

## Морская поверхность

В текущей версии самописная процедурная вода заменена готовыми `Water.js`, `Sky.js` и `waternormals.jpg` из Three.js r170 (`examples/jsm/objects` и `examples/textures`). Копии модулей сохранены локально; изменён только путь импорта Three.js. Основа отражений и освещения остаётся из официального примера. Адаптер добавляет небольшое вертикальное смещение сетки и регулятор силы волн. Макрос имени `average` обеспечивает совместимость common-chunk с glslang 12.

Стартовый ракурс — общая карта с той же водой Three.js Ocean. Восемь фоновых сухогрузов автоматически движутся туда и обратно по морским полилиниям; пауза останавливает воду и флот. Геометрия и материалы кораблей используются совместно. Отдельный запуск путешествия временно убран из интерфейса: выбор страны сразу показывает её маршрут, фоновый флот движется автоматически. «Карта» возвращает обзор маршрута, «Море» приближает к судну. В морском виде один палец вращает камеру, два управляют расстоянием. При прохождении маршрута камера перемещается вместе с кораблём. В обзоре вода также использует тот же готовый материал. Старый эффект от касаний удалён вместе с самописным шейдером.

Проверена компиляция и линковка шейдеров воды, неба и суши в GLSL ES 3.00 с реальным компилятором. Браузерная визуальная проверка и измерение FPS на iPhone / целевом выставочном компьютере не проводились; сходство с Anno не гарантируется.
