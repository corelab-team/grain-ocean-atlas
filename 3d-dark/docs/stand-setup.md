# Стенд: панель 4K и ноутбук на Windows

Панель: 3840×2160, 60 Гц, 10 одновременных касаний, 50 дюймов.
Ноутбук: Windows, видеокарта RTX 4060.

## Как приложение ведёт себя на 4K

Все экраны свёрстаны в координатах 1920×1080 и на панели увеличиваются
ровно в два раза, без полей: пропорции 16:9 совпадают. Текст, панели,
кнопки и иконки рисует браузер, они чёткие в любом разрешении. Глобус
и карта России рисуются в родном разрешении экрана.

Растровые картинки — единственное, что зависит от исходников: сцена
шириной 1920 px на панели растянута вдвое и выглядит мягче текста.
Нужные размеры — в `docs/assets-4k.md`. Заменить картинку: положить
исходник с тем же именем в `assets/concept/src` и запустить
`python3 tools/make_concept.py`. Координаты в коде менять не нужно.

## Запуск

1. Собрать приложение: `python3 tools/publish_pages.py`. Нужен один файл —
   `dist/app/index.html` (всё внутри, интернет не нужен).
2. На ноутбуке создать папку, например `C:\stand`, положить туда этот файл
   под именем `app.html` и `stand/start-kiosk.bat`.
3. Запустить `start-kiosk.bat`. Chrome откроется на весь экран без рамок.
   Выход — Alt+F4 с клавиатуры.
4. Для автозапуска положить ярлык на `start-kiosk.bat` в папку
   автозагрузки (Win+R → `shell:startup`).

Ярлык запускает Chrome с отдельным профилем в папке `chrome-profile`,
отключает масштабирование щипком, жест «назад» по краю, подсказки
о восстановлении вкладок и разрешает автозапуск видео.

`--force-device-scale-factor=1` в ярлыке означает: приложение само
растягивается под экран, масштаб Windows (150–200 %) на него не влияет.
Если на панели всё выглядит мелко или обрезано — уберите этот флаг.

## Настройка Windows на ноутбуке

| Что | Где | Зачем |
|---|---|---|
| Панель — основной экран, 3840×2160, 60 Гц | Параметры → Дисплей | иначе Chrome откроется на экране ноутбука |
| Chrome на дискретной видеокарте | Параметры → Дисплей → Графика → добавить chrome.exe → «Высокая производительность» | стеклянные панели и глобус в 4K тяжёлые для встроенной графики |
| Питание: не спать, не гасить экран, не отключаться при закрытой крышке | Параметры → Питание | стенд работает весь день |
| Жесты по краям экрана выключить | Параметры → Bluetooth и устройства → Сенсорный ввод → жесты тремя и четырьмя пальцами: выкл. | посетитель не должен вызвать рабочий стол или центр уведомлений |
| Уведомления и «Фокусировка» | Параметры → Система → Уведомления: выкл. | всплывающие окна поверх стенда |
| Обновления Windows приостановить на время выставки | Параметры → Центр обновления | перезагрузка посреди показа |
| Сенсор привязать к панели | Панель управления → Параметры планшетного ПК → Настроить | касания должны попадать на панель, а не на экран ноутбука |

## Что защищено в самом приложении

Общий модуль `src/util.js` на всех страницах отключает: контекстное меню
по долгому касанию, выделение текста, перетаскивание картинок,
масштабирование страницы щипком и через Ctrl + колесо. Поле поиска
остаётся рабочим. Жесты разделов — вращение и щипок на глобусе,
перетаскивание карты — работают как раньше. Для отладки защиту можно
снять параметром адреса `?kiosk=0`.

## Проверить на панели перед показом

- касания попадают точно: нажать кнопки в четырёх углах экрана;
- глобус вращается плавно, щипок приближает;
- список стран и «Топ-10 регионов» прокручиваются пальцем;
- через 90 секунд без касаний приложение возвращается на заставку
  (время — `attractorTimeoutSec` в `config.json`);
- долгое касание нигде не вызывает меню, двойное касание не увеличивает страницу.

## Служебные пометки

Метки «[VIDEO]» на входном экране глобуса, подпись «новости демонстрационные»,
пометки у филиалов без данных посетителю не показываются. Увидеть их при
работе над стендом: добавить в адрес `?notes=1`. Пометки «демоданные»
у цифр остаются всегда — это честное предупреждение о характере данных.


Ручная настройка трёх общих итогов мониторинга: на карте мониторинга нажмите Ctrl+Alt+M.
Введите общий валовой сбор зерновых, зернобобовых и масличных, валовой сбор пшеницы и обследованный объём в тыс. т и нажмите «Сохранить».
Настройка доступна только для 2026 года и хранится локально и меняет только три цифры «Всего по России».
Данные регионов, классы, рейтинг и процент соответствия ГОСТ не пересчитываются.
«Сбросить» удаляет настройку 2026 года и возвращает значения из свода.
